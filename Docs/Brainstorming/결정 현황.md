### 서브그래프 상세

- **접기**: 같은 파일 안에서 노드 묶음을 보기만 접는다. 재사용하지 않는다 (Unreal Collapse Nodes)
- **참조형 서브그래프**: 워크스페이스에 별도 JSON 파일로 두고, 쓰는 쪽은 참조한다. 원본을 고치면 모든 사용처에 **다음 실행부터** 반영된다 (Unreal Function/Macro, Robot Framework 사용자 키워드, Maestro `runFlow`)
- **인터페이스**: exec 입력 1개, exec 출력 여러 개(예: `성공` / `점검 중` / `로그인 실패`), data 입출력 핀
- **화면 선언**(선택): 출구마다 도착 화면을 적는다. 화면 지도에 출구별 전이로 기록한다
- **ensure는 넣지 않는다**: 화면만 보고 건너뛰면 다른 계정·서버로 접속한 상태에서도 성공이 된다 (Codex 리뷰)
- **변수 범위**: 서브그래프 안의 변수는 밖과 분리한다. 값은 핀으로만 주고받는다. data 연결은 현재 호출 프레임에서 이번 경로에 만들어진 값만 읽는다
- **현재 대상 창**: 호출한 쪽의 창을 이어받는다. 노드의 `window` 입력은 그 노드에만 적용된다
- **실패 전파**: 안에서 처리되지 않은 실패는 호출 스택을 따라 테스트까지 올라간다. 호출한 쪽이 잡을 실패는 공개 출구로 만든다. 종료 노드(pass/skip/fail)는 테스트에서만 쓴다
- **실행 기록**: 서브그래프 노드를 펼치면 안쪽 노드의 기록이 보인다. 실패 위치는 `테스트A > 월드접속 > 로그인버튼찾기` 같은 경로로 표시한다. 실행에 쓴 서브그래프는 실행 폴더의 스냅샷으로 남는다
- **디버깅**: 브레이크포인트에서 Step Into / Step Over
- **실행 전 검증**: 순환 참조와 최대 깊이를 검사한다. 반복에는 횟수 한도, 테스트 전체에는 기한을 둔다
- **파급 관리**: 사용처 찾기, 수정 시 영향받는 테스트 목록
- **Agent·MCP**: 서브그래프 하나를 MCP 도구 하나로 노출한다. 이때 안쪽 노드가 요구하는 권한(프로세스 실행·비밀값·입력)을 합쳐서 검사한다. Agent는 검증된 서브그래프를 조립해 테스트를 만든다. "결정적 노드로 굳히기"의 결과도 서브그래프로 저장한다
- **이후 버전**: fixture 방식 상태 공유(로그인 한 번을 여러 테스트가 공유), exec 없는 순수 함수, 버전 고정·업그레이드 UI, 화면 지도로 서브그래프 경로 자동 탐색
