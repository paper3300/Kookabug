# 01 — 고요한 옆얼굴
커다란 머리와 긴 수평 부리를 중심으로 정돈한 검은 흉상.
넓은 흰 눈 줄무늬와 짧은 부리 틈으로 쿠카부라의 인상을 남긴다.

# 02 — 웃음의 순간
고개를 들고 부리를 벌린 쿠카부라를 흰 실루엣으로 표현한다.
벌어진 두 부리 사이의 검은 여백이 웃는 동작과 표정을 만든다.

# 03 — 가지 위의 작은 주인
큰 머리, 접힌 날개, 짧고 통통한 몸을 가진 왼쪽 방향의 전신.
단순한 수평 가지와 두꺼운 꼬리로 안정적인 앉은 자세를 잡는다.

# 04 — 둥근 선의 새
16px 굵기의 둥근 선으로 머리와 몸을 하나의 외곽선에 담는다.
넓은 빈 몸통과 짧은 날개 곡선이 가볍고 친근한 인상을 만든다.

# 05 — 둥지의 인장
검은 원 안에 몸을 둥글게 모은 흰 새를 넣은 원형 배지.
검은 날개 음각과 작은 꼬리가 원의 곡률에 맞춰 시선을 모은다.

# 06 — 기울인 시선
부리를 아래로 기울이고 가슴을 넓게 드러낸 흰 초상.
굵은 눈 줄무늬와 목 아래 검은 음각으로 얼굴과 가슴의 방향을 나눈다.
