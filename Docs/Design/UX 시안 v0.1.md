## 디자인 방향

- **앱 틀은 VSCode 방식**
  - 타이틀 바(가운데 명령 검색 Ctrl+P), 액티비티 바, 사이드바(섹션별 접기), 에디터 탭 + 경로 표시줄, 하단 패널 탭, 상태 바
  - 차분한 회색 다크 톤에 강조색은 파랑 하나. 모서리는 각지게, 글자는 촘촘하게
  - 상태 바 색으로 지금 상태를 표시: 실행 중 파랑 / 녹화 중 빨강 / Agent 탐색 중 보라 / 대기 중 회색
- **우측 에이전트 패널은 Aside 방식**
  - 세션 제목 + 새 대화 버튼
  - 내 메시지는 오른쪽 말풍선, 에이전트 답변은 말풍선 없는 본문
  - 도구 호출은 "작업 9초 · 도구 2개 ›"처럼 한 줄로 접고, 진행 중이면 펼쳐서 표시
  - 승인 요청은 카드로 표시: 한 번 허용 / 항상 허용 / 거부
  - 입력창: 둥근 상자 + 첨부 버튼 + @첨부 칩 + 원형 보내기·중지 버튼. 아래 줄에 에이전트 이름, 권한 프리셋, MCP 상태
- VSCode 기본 다크 테마와 분위기만 비슷하게 맞추고, 그대로 복제하지 않는다
- 예시 게임은 가상의 "SampleRPG"

## 첫 실행 흐름

새 프로젝트를 만들 때는 설정 화면이 먼저 나오고, 끝나면 노드 에디터(1번 화면)가 열린다. 레이아웃은 Aside 온보딩을 참고했다: 왼쪽에 설명과 입력, 오른쪽에 그림, 아래에 이전 · 진행 점 · 다음(↵). 색은 툴과 같은 어두운 톤. 캔버스에서 Play로 이전·다음을 눌러 넘겨 볼 수 있다.

| 단계 | 화면 | 정하는 것 | 근거 |
|---|---|---|---|
| 0 | 시작 화면 | 시작하기 / 이미 있는 프로젝트 열기 | |
| 1 | 프로젝트 만들기 | 빈 프로젝트 또는 예제 게임, 이름, 위치, Git 저장소 여부. 오른쪽에 만들어질 폴더 구조 | [[워크스페이스 구조]] |
| 2 | 게임 연결 | 떠 있는 창 고르기 또는 실행 파일로 띄우기. 실행 파일 경로는 이 PC에만 저장. 오른쪽에 실시간 캡처 | `.kookabug/local.json` |
| 3 | 환경 점검 | 화면 캡처, OCR, DPI, 입력 전달(관리자 권한), 창 모드를 시험. 경고가 있어도 계속 가능 | [[구현 계획 v0]] 5장 |
| 4 | 테스트 계정 (선택) | 키·아이디·비밀번호. Windows 자격 증명 관리자에 저장, 그래프에는 키 이름만 | [[워크스페이스 구조]] 비밀값 |
| 5 | 에이전트 연결 (선택) | 감지된 에이전트 CLI / API 키 / 연결 안 함, 권한 프리셋 | 결정 현황 Agent 패널·권한 |
| 6 | 기록 정책 | 노드별 스크린샷, 영상(끔/실패만/항상), 보관 기간. 민감 구간 안내 | [[그래프 JSON 스키마 v0]] 6장 |
| 7 | 완료 | 설정 요약, 처음 할 일(녹화 / 에이전트에게 맡기기 / 빈 에디터) → 에디터 열기 | |

- 에이전트 로고는 다른 회사 디자인이라 넣지 않고 글자 아이콘으로 대신했다
- 3단계의 경고(관리자 권한)는 막지 않고 완료 화면 요약에 남긴다
