# targets

사람이 실제 게임 화면에서 만든다 (절차서 G0 4단계). 이 폴더를 레포 밖에 복사한 사본에 둔다.

| 파일 | 내용 |
|---|---|
| `anchor.png`·`anchor.target.json` | 기준 버튼 |
| `label.png`·`label.target.json` | 확인 글자 줄 |
| `field.png`·`field.target.json` | 비어 있는 입력 칸 |

target 파일: `{"format":"kookabug.target/0","image":"anchor.png","recorded":{"client_size":[W,H],"dpi":96}}` — `W, H`는 배율 100%에서 찍은 화면 PNG의 크기(클라이언트 크기)다.
